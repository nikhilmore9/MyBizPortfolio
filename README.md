# Nikhil More — Personal Site

Personal executive-brand website for Nikhil More: AI-First Demand Generation, Revenue Marketing & Performance Marketing Leader. Built with Next.js (App Router), TypeScript and Tailwind CSS v4.

## Stack

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Styling:** Tailwind CSS v4, CSS-variable design tokens for light/dark theming
- **Theme:** `next-themes` (dark by default, toggle in header, no-flash on load)
- **Icons:** `lucide-react` (plus a small inline SVG for the LinkedIn mark, which lucide-react no longer ships)
- **Motion:** `motion` (Framer Motion's successor package), used sparingly for reveal transitions
- **Images:** `next/image` with local assets in `public/images`, optimized at build/request time (`sharp` installed as a dependency)

## Content

All copy, metrics, case studies, experience and capability data lives in `src/data/content.ts`, sourced only from `Nikhil_More_Resume_2026.pdf`. Update that file to change any on-page facts — components read from it rather than hardcoding copy.

## Structure

```
src/app/            Root layout, page, metadata routes (robots.ts, sitemap.ts)
src/components/      Page sections (hero, impact metrics, growth system diagram, case studies, experience timeline, about, contact, footer, meeting modal, header)
src/components/ui/   Small reusable primitives (container, section heading, count-up/in-view hooks, signal lines, LinkedIn icon)
src/data/content.ts  Single source of truth for all on-page copy and structured content
public/images/       Headshots (optimized to ~1600px max width)
public/Nikhil_More_Resume_2026.pdf  Downloadable resume served at /Nikhil_More_Resume_2026.pdf
```

## Deployment

Any Next.js-compatible host works (Vercel is the simplest path: `vercel deploy`). No environment variables or backend services are required — the contact form has no email backend and instead opens a pre-filled `mailto:` link, and meeting requests route to LinkedIn.

## Notes / assumptions

- **Theme default:** dark mode is the default on first visit (per design spec); `next-themes` is configured with `enableSystem` so an explicit "system" preference is still honored if a user selects it, but the initial unauthenticated visit is dark, not OS-driven.
- **Domain:** metadata (`metadataBase`, OpenGraph, sitemap, robots) references `https://nikhilmore.com` as a placeholder — update `src/app/layout.tsx`, `src/app/sitemap.ts` and `src/app/robots.ts` once a real domain is chosen.
- **Contact form:** intentionally has no backend. It validates fields client-side and, on submit, opens the visitor's email client with a pre-filled `mailto:` message — this is disclosed in the UI copy so no false "sent" state is ever shown.
- **Favicon:** using the placeholder generated by `create-next-app`; swap `src/app/favicon.ico` for a branded mark when one exists.
